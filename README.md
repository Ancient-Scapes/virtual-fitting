# Virtual Fit

バーチャル試着を体験できる Next.js デモアプリです。Google アカウントでログインし、自分の写真と気になる服の画像・サイズを入力すると、Gemini 2.5 Flash Image が「自分がその服を着たイメージ」を生成します。仕上がった画像と一緒に、フィット感の★評価やコメントも確認できます。

## できること
- **ワンクリック試着プレビュー**: 自分の全身写真と服の画像をアップロードすると、AI が試着イメージを作成。
- **フィット感の自動判定（任意）**: 体型と服のサイズを入力すると、肩幅・着丈をもとにスコア化し、★評価とコメントでフィードバック。
- **履歴の自動保存**: 直近の入力内容と生成結果をブラウザに保存。ページを開き直してもすぐ続きから試せます。
- **再試行も簡単**: 結果画面からワンクリックで再生成や画像ダウンロードが可能。

## 使い方（デモ環境がある場合）
1. `/login` で Google アカウントにログイン。
2. `/tryon` で以下を入力し、「試着する」を押すだけ。
 - 自分の全身写真（長辺 1024px に自動リサイズ）
 - 服の写真
  - 数値（身長 / 肩幅）※服の肩幅 / 着丈は任意入力。入力するとフィット評価が表示されます。
3. `/result` で生成された試着イメージ、フィット評価、コメント、サイズ比較表を確認。画像はそのままダウンロード可能。

## 開発メモ
- Next.js (Pages Router) + Supabase Auth (Google OAuth) + Gemini 2.5 Flash Image API
- モバイルでも操作しやすい Vaporwave テイストの UI を採用
- GitHub Actions で main branch へのマージをトリガーに Vercel へ自動デプロイ

> 採用担当・非エンジニアの方でも、README を参考に「ログイン → 写真とサイズ入力 → AI 試着 → 結果確認」という流れを体験できます。
